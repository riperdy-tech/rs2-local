## 1. WHAT WE DID, AND WHY

### 1.1 The methodology audit (phases A–E)

Started as a standards review; became a demolition. Documents: `A_institutional_checklist.md`,
`B_gap_analysis.md`, `C_findings.md`, `VALUATION_AUDIT_202608.md`, `D_base_contamination_20260819.md`,
`E_methodology_verdict_20260820.md`, `F_config_findings_20260820.md`.

The finding that reframed everything: **RS2's published fair value is arithmetically
`base_cf × M(growth, wacc) × price / market_cap`.** `dcf_value` is homogeneous of degree one in
`base_cf`, so the DCF contributes only a scalar. Measured: R² of the published valuation on the
trailing scalar alone **0.885**; on the entire DCF apparatus **0.025**; Spearman of the MoS
ranking against the raw ratio `base_cf/market_cap` **0.928**. It ranks by one trailing accounting
yield and re-denominates it into dollars.

**Retracted from earlier in this same session:** the C6 retrodictive evidence that justified
"refine, don't rebuild". A null signal — "buy whatever fell over the last 3 months" — predicts the
same forward returns *better* (ρ **+0.567** vs **+0.404**), and the sample was 8 entry dates in one
overlapping 30-day window that happened to be the most reversal-favourable month in 16. C2 and
C4 fell too. **Do not cite C1–C6 as evidence for anything.**

### 1.2 O1/O2 changes shipped to the valuation engine

expenses SBC); cost-of-equity level anchored to the book's own implied rate (+1.7/1.8pts);

### 1.3 The local model was never the bottleneck

The operator challenged "the model isn't good enough". They were right. Given honest data,
thinking on, one long context and permission to own the analysis, the **same** local model
caught GOOG's contamination unprompted — *"Q2 2026: revenue $119.8B, NI $112.2B → 93.7% margin??
That's absurd"* — triangulated the one-off at ~$77B (actual $76.6B), and built a ten-year driver
forecast. The production pipeline, same model same data, published **$702.49 / +97.4%
undervalued**.

The cage, all verified: `think=False`; *"DO NOT select a valuation engine"*; *"The intrinsic value
is NOT yours to compute"*; a field-ownership contract forbidding the model from printing a
different value; an auditor that treats the engine's number as AUTHORITATIVE and **fails a report
that corrects it**; 4,500-char carry truncation; and an evidence pack that withheld cash flow.

### 1.5 The data extraction rewrite (the biggest durable win)

Census found **20.4% of D&A, 17.2% of revenue, 16.9% of pretax ticker-years null** across the
book — filed values the extractor never read.

Two premises were wrong, including mine. `ifrs-full` was **already merged**, and the USD filter
was **not** blocking (all 10 stuck foreign filers carry D&A in USD). The real cause:
`annual_duration_series` picks **one winning tag** and never mixes, so it drops years the winner
lacks even when an already-mapped tag covers them. **Stitching, not new tags, is ~85% of the fix.**

Also caught before shipping: "just add `Depreciation`" would have understated **Novartis by 76%**
($1,208M vs a true $4,949M). It ships as a verified allowlist `{GOOG, GOOGL, UNP}`, never a rule.
And passing an expanded tag list to the primary vote **lost 13 capex values** — the primary is now
computed over the original list so additions can only backfill.

### 1.6 The depth tier and its guards

`capability_test.py` (pack builder + task), `consensus_valuation.py` (N seeded samples,
plausibility guard, tolerance), `analyst_tools.py` (search during reasoning, every call
snapshotted), `grade_capability.py` (8 checkpoints).

Plausibility thresholds are calibrated against six reference points, **asymmetric on purpose**
(this book is structurally bearish; far below analysts is ordinary, far above is farfetched).
Must reject our own $702.49 (1.63× the PV'd analyst high; 46.3× TTM OCF) and a $1,108.91
fabricated-NI stress case, while passing $205 / $280–310 / both arms.

### 1.7 Letting the model search (operator's idea, and it worked)

The sanity audit found all three Q5 runs had **invented** a 2027+ capex path — the pack carries
2026 guidance only — and that single assumption decided the answer. Holding everything else and
refusing the assumed collapse moved them from $317/$321/$273 to **$204/$178/$149**.

With search enabled the model fetched Alphabet's actual SEC 8-K exhibits and queried
*"Alphabet 2027 capex 'increase significantly' Ashkenazi guidance"*. Valuations moved from a
no-tools median of **$270** to **$240 and $161**, bracketing the $205 benchmark.

   session.* `stage_ctx` went 24,576 → 49,152, so five stages can now run 34–50 min at the

## 2b. THE TARGET ARCHITECTURE — write this down, it is the point of §2

The individual items above are cleanup. **This is the design they are clearing the way for**, and
it should be stated as a target rather than inferred from a list of removals.

> **The AI writes the spec. The code executes it. The guard judges the output.**

| Layer | Owns | Must never |
|---|---|---|
| **AI (analyst)** | *What* and *how* to compute: which cash-flow definition (FFO / owner earnings / mid-cycle / normalized / explicitly ex-one-off), which engine, the per-year driver path, the discount rate and its derivation — each emitted as a **structured value with a source tag**, not prose | Do the arithmetic |
| **Code** | Executing that declared spec: assemble base_cf from the stated definition, run the DCF, per-share, terminal | Choose anything. No tree, no fallback ladder, no silent substitution |
| **Guard** | Plausibility (calibrated, binding) + repeatability (N seeded samples, tolerance) | Rewrite. It **refuses**; it does not correct |

**Why this and not today's split.** Today the code chooses AND computes (`_base_cf` picks by
hard-coded tree; the model never touches it) — and `base_cf` selection is precisely what produced
GOOG's $702.49. The lattice half-admits the choice is a judgment but offers only three
pre-computed cells and a 3-way vote; the model cannot say *"none of these — use owner earnings
excluding the equity gain."* Meanwhile the depth tier over-corrected: the model picks **and** does
the arithmetic in-context, and the sanity audit measured real errors in 2 of 3 reports (a
double-counted terminal-growth year, +3.0%; a stated 6.00% spread applied as 5.80% plus a $10B row
error, +3.9%). Judgment to the model, arithmetic to the machine.

**⚠️ This reverses a documented decision and must be earned, not assumed.** AUDIT.md C2 recorded
that letting the model supply base_cf/growth/WACC was *demonstrably worse*. Two conditions have
since changed — the data was bad then (17.2% of revenue null; GOOG's lattice collapsed to one
cell) and the model had no room to reason (`think=False`, 4,500-char carry) — and one thing is
genuinely new: **there was no plausibility guard or consensus check, so an invented number
published straight through.** Now it would be refused.

**Work item (belongs after §2 step 5, alongside step 7):**
1. Define the structured spec the model emits — flow definition, driver path, rate, each with a
   source tag. Extend `S3_valuation_inputs.json`; do not invent a new artifact.
2. Make `valuation_backbone` able to compute from a supplied spec as well as from its own tree.
3. **Shadow arm, not a swap**: run spec-driven alongside tree-driven on the same names, publish
   neither, and compare. Pre-register what "better" means before looking — at minimum: fewer
   plausibility refusals, tighter consensus spread, and no increase in arithmetic errors.
4. Only promote if the shadow arm wins on all three. A tie means keep the tree — it is cheaper
   and already understood.

## 4. THINGS THAT ARE TRUE AND UNCOMFORTABLE

- **Unshackling does not fix instability.** Six unshackled runs on GOOG span **$161–$335 (2.08×)**.
  One free-arm report named three different intrinsic values in one document — exactly what the
  field-ownership rule exists to prevent, produced unprompted by the free arm.
- **Better data made the model disagree *more*.** Consensus spread went 14.8% → 31.4% once the
  analyst-target bug was fixed. Tolerance is necessary, nowhere near sufficient.
- **The 14.8% "convergence" was compensating errors.** Two of three runs had effectively the same
  cash-flow forecast (within $0.70 at any discount rate); the entire gap was the discount rate;
  and the ranking was inverted — the most aggressive cash flows produced the *lowest* IV.
- **Both published GOOG numbers are wrong.** $64.30 subtracts ~$100B/yr of build-out as
  maintenance capex; $702.49 capitalises a contaminated base.
- **My own harness reproduced the bugs it was auditing**: analyst targets withheld by a key typo
  (`target_low` vs `analyst_target_low`), the pack never saved so runs weren't re-auditable, a
  guard scoring the model against evidence it was never shown, and a grader with three
  false negatives — every one of which flattered the conclusion I already held.
